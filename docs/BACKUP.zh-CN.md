# 备份与任务恢复

实现与验证日期：2026-10-01。入口位于「设置 → 备份与恢复」「设置 → 后台任务与通知」。

## 备份格式与范围

用户备份是 ZIP，格式版本为 1。`manifest.properties` 列出每个文件的长度和 SHA-256；恢复拒绝未知版本、未知文件、重复项、路径穿越、缺失文件、校验不符及超限展开。单项上限 64 MB，总展开上限 512 MB，最多 100000 项。数据库采用固定表及固定列的逻辑快照；当前仅支持数据库 schema 11，结构不匹配会明确拒绝。

包含全局/阅读设置、图库来源与漫画/章节索引、书架分类、进度与已读状态、漫画字典、章节翻译记录、页译文及人工编辑、用户工作流、API 配置、语言包下载源设置及翻译队列顺序/排除页。API 配置和任务配置快照中的 API Key 默认为空。

不包含原始漫画、模型包、API 请求日志、导出产物、导出队列和导出临时快照。模型需要重新安装；导出队列及私有快照用于同一安装中的恢复，不是跨设备迁移内容。Android 自动备份/设备迁移同样排除导出队列及其旧版/临时状态文件，避免发布日志与私有快照脱离。目录授权由 Android 管理，备份保存的是路径线索，恢复后需要重新选择原目录；跨提供方移动导致 documentId 改变的重新关联仍不在本实现范围。

## 恢复与回滚

先完整展开、验证包和数据，再停止翻译/单页任务、导出与扫描，等待写入者收尾。恢复前在 `noBackupFilesDir` 保存完整本机回滚副本，同步到磁盘后写入 `restore-pending` 指针。

数据库替换在 Room 事务中执行；偏好通过当前 DataStore/SharedPreferences 实例恢复，不替换打开中的 protobuf。页数据与工作流采用原子文件替换。任何失败会恢复本机回滚副本；进程在跨资源恢复中被终止时，下次启动先处理回滚日志，完成之前不启动队列、索引维护和主导航。无法完成回滚时保留副本并显示明确错误，同时阻止当前会话继续使用主界面，避免带着一半恢复的数据继续运行。

恢复成功后翻译/导出队列保持暂停，未完成翻译记录标为中断，来源标为需要重新授权，导出目录清空并保留旧目录线索。重新填写 API Key、安装所需模型并授权路径后，由用户继续任务。恢复的语言在重新打开应用后生效。

## 已完成任务自动出队

章节翻译完成后自动退出队列，章节完成状态、已译页数与译文继续保留。导出完成且发布日志与临时快照清理结束后自动出队，目标文件继续保留。启动时也会处理旧的已完成任务；失败、中断、暂停任务保留供继续或重试。清理或队列保存失败时保留完成记录与错误，避免丢失恢复依据。

## 后台任务与中断

翻译队列、导出队列和阅读器单页翻译执行前都需要前台服务确认，运行期间持有任务 lease；最后一个写入者收尾后才移除通知。使用 `dataSync` 类型、对应权限、低优先级通知通道和有超时的部分唤醒锁。通知显示翻译/导出章节数及当前页面/进度，可打开相应队列并暂停全部任务；通知权限未允许时，后台任务仍能运行，设置页说明通知栏不会显示进度。

切换页面、切到后台和锁屏不主动取消章节队列。普通翻译暂停停止调度并保留当前页/整漫画响应的完成结果；导出暂停停止写入，保留私有快照。取消保留已有译文；不会继续发布被取消的输出。

服务停止或后台时限到达时持久化暂停状态、取消写入者，并立即停止服务；重新开始需要用户回到应用操作。进程被终止后，运行中章节标为中断，保存的译文继续保留，不假装恢复任意工作流中间变量。使用 `START_NOT_STICKY`，不在后台静默重启服务。

Android 15 起 `dataSync` 服务受后台时限约束，处理 `onTimeout` 不能省略；限制依据见 [Android 官方前台服务超时说明](https://developer.android.com/develop/background-work/services/fgs/timeout)。本实现不承诺规避厂商省电策略或无限后台运行。

## 导出快照和发布日志

每个任务在 `noBackupFilesDir/export-staging/<任务 UUID>` 保存原图、译文/渲染设置和页面顺序快照。译文捕获与阅读器编辑、翻译发布共用锁；原图复制在锁外进行。快照完成标记出现之前不用于输出；渲染页面有独立校验记录，暂停和重试复用完整页面，损坏或未提交页面重新生成。原图快照与章节输出分别有 2 GB 上限，快照占用会增加应用私有存储空间。

发布前先持久化 `.lmreader-<任务 UUID>.part` 的预留记录，再创建目标文件，并记录 URI。复制关闭后重新读取目标校验字节和页数，再记为 READY；成功重命名后才能提交 DONE 与最终 URI。目标名称冲突自动编号，原始漫画保持不变。

启动恢复能够定位「文件已创建但 URI 尚未记录」的临时文件；也能识别「已重命名但 DONE 尚未写入」的完整产物，收敛为 DONE，避免重复导出。部分产物只清理任务拥有的临时文件；清理失败保留日志和错误，不清空追踪信息。清除已取消不会丢弃仍待清理的临时记录。队列 JSON 损坏时保留原文件并停止修改，避免静默覆盖为空队列。

无待清理发布记录的失败任务重试时可以使用重新选择的导出目录；尚有旧目录临时文件时，需要先恢复旧目录授权以清理。设置中的「暂停导出并清理临时文件」清理远端暂存和已取消缓存，保留可继续的快照。

本轮同时修复 SAF 文档 ID 的重复百分号编码及重复 URL 解码，保证斜杠、加号、百分号和中文 ID 保持原值。

## 验证与边界

恢复与导出的设备测试使用隔离数据库、偏好和专用 DocumentsProvider。此前 14 项可靠性测试覆盖备份回滚、损坏日志阻断、三格式输出、发布中断窗口、快照重试、临时清理和服务控制。当前自动出队回归用例已编译，本轮未重跑设备测试；构建与 JVM 检查见[发布准备](RELEASING.zh-CN.md)。

ARM 长时间锁屏、省电策略、真实 SD 卡或云提供方，以及任意时刻的系统杀进程仍需实机验收。工作流中间变量恢复、更多导出格式和跨 schema 备份迁移尚未提供。
