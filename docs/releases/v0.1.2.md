# v0.1.2 — OCR 闪退与设置导航修复 / OCR crash and settings navigation fixes

发布日期 / Release date: **2026-10-02**. Version code: **4**. Package: **com.lmreader**. Android **8.0+ / API 26+**; **arm64-v8a / x86_64**.

## 中文

- 修复正式版加载本地 OCR 时闪退：保留 ONNX Runtime 的 JNI 构造方法，避免 `NodeInfo` 构造方法被 R8 删除后触发原生进程退出。问题来自 Android 16 手机的实际崩溃日志。
- 修复 SEG GPU 初始化失败时的闪退：保留 LiteRT 的 JNI 类型和异常构造方法，使 GPU 不可用时能正常回退 CPU。
- 修复正式版打开阅读器时图片解码库的 JNI 构造方法被删除导致的闪退。
- 设置子页面保留调用页面的返回栈。“设置 → 导出设置”点返回或系统返回键均回到设置；阅读器设置、图库路径、OCR/SEG 配置及测试页同样返回上一级。
- 发布打包与 GitHub CI 直接检查 APK 内的 JNI 构造方法，防止只通过 Debug 测试却发布无法运行的压缩正式版。

使用与 v0.1.0 / v0.1.1 相同的发布证书，可覆盖安装；漫画、译文、队列和设置保留。此前因闪退显示“上次运行被中断”的任务，可升级后手动重试。

## English

- Fix the release-only local OCR crash by retaining ONNX Runtime JNI constructors. R8 had removed the `NodeInfo` constructor, causing a native abort. The diagnosis is based on actual Android 16 phone crash logs.
- Retain LiteRT JNI types and exception constructors so unavailable SEG GPU acceleration can fall back to CPU safely.
- Fix the release reader crash caused by removed JNI constructors in its native image decoder.
- Preserve callers in the navigation stack for settings children. Toolbar and system Back from Settings → Export settings return to Settings. Reader/path settings, OCR/SEG configuration and test pages also retain their parent.
- Packaging and GitHub CI inspect JNI constructors in the actual APK to detect release-only failures that Debug testing misses.

The APK uses the same signing certificate as v0.1.0 / v0.1.1 for in-place upgrades. Manga, translations, queues and preferences are retained. Manually retry tasks marked interrupted after upgrading.

## 验证 / Verification

- Release build, Debug/Release lint and JVM tests passed: 420 passed, 1 skipped, 0 failed.
- MuMu Android 15 navigation regression test passed, covering export toolbar/system Back, reader/path settings and nested SEG settings.
- Signed, R8-minified production APK GUI checks: export returns to Settings; English and Korean SEG + OCR complete; unavailable GPU falls back to CPU.
- A generated one-page manga completed the actual local-machine queue through SEG → OCR → Bergamot translation → saved translations. Its translated reader page opens successfully.
- APK JNI checks reject the previous v0.1.1 artifact and accept this version. Signing, package/version, model hashes, ABI and 16 KB alignment checks are included in packaging.

The phone was disconnected after crash logs were collected, so post-fix physical-phone testing remains pending. MuMu verification does not establish long-running behavior on every physical GPU/NPU device.
