# v0.1.0 — First release / 首版

**状态 / Status:** 已签名首版 APK。First signed APK release. Version code: **2**. Package: **com.lmreader**. Android **8.0+ / API 26+**; **arm64-v8a / x86_64** only.

## 中文

首版接通图库 → 阅读 → 本地/API 翻译 → 气泡编辑 → 队列与导出的主要流程。

- 图片目录、ZIP、CBZ、PDF 阅读；书架分类、搜索、排序与阅读进度。
- 本地 Seg/OCR、按需机翻包、图片/文本 API 和三种猫爪参考模板。
- 原图上的译文/气泡浮层、人工修改、撤销和保存，漫画译名字典。
- 工作流编辑与导入/导出、本机 API 绑定、步骤/并发监视。
- 翻译/导出前台服务、进度通知、暂停/取消/重试及中断状态收敛。
- PNG/JPEG 图片目录与 CBZ；固定原图/译文快照、完整性校验和临时文件恢复。
- 设置/书架/进度/字典/译文备份，恢复前回滚副本及启动恢复；密钥默认不备份。
- 简体中文/英语界面。跟随系统：简中系统使用简中，其他语言（含繁中）使用英语；手动语言优先。

恢复后重新授权目录、填写 API 密钥、安装模型并手动继续任务。Debug 与 Release 是独立包，迁移通过备份/恢复。进程终止后中断任务需手动重试；任意工作流中间变量、旧译文历史、PDF/ZIP/WebP 输出、跨 schema 备份迁移尚未提供。

APK 使用专用 RSA-4096 发布密钥签名，已通过 APK Signature Scheme v2/v3 与 16 KB 对齐校验。附件包含校验清单、签名证书指纹与第三方声明。ARM 长时运行、覆盖安装升级仍待验收；模型分发依据和项目许可证选择尚未完成。

- 关于页面：当前版本、GitHub 项目主页与正式发行更新检查。

## English

The first release connects the main library → reading → local/API translation → bubble editing → queue/export flow.

- Image-folder, ZIP, CBZ and PDF reading; shelf categories, search, sorting and progress.
- Local Seg/OCR, optional offline translation packs, image/text APIs and three Cat-paw reference templates.
- Translation/bubble overlays on originals, manual edits, undo/save and a per-comic glossary.
- Workflow editing/import/export, local API binding and step/concurrency monitoring.
- Foreground translation/export services, progress notifications, pause/cancel/retry and interruption reconciliation.
- PNG/JPEG folders and CBZ, fixed source/translation snapshots, integrity checks and temporary-file recovery.
- Settings/shelf/progress/glossary/translation backups, pre-restore rollback copies and startup recovery; API keys excluded by default.
- Simplified Chinese/English UI. Follow system selects Chinese only for a Simplified Chinese primary system language; all others, including Traditional Chinese, use English. Manual selection takes priority.

After restoration, reauthorize folders, enter API keys, install models and resume manually. Debug/Release are separate packages; migrate through backups. Process termination requires manual retry. Arbitrary workflow checkpoints, old translation history, PDF/ZIP/WebP output and cross-schema backup migration are unavailable.

The APK uses a dedicated RSA-4096 release key and passes APK Signature Scheme v2/v3 and 16 KB alignment checks. Assets include checksums, signer certificate fingerprint and third-party notices. ARM long-running and upgrade validation, model distribution evidence and the project license selection remain pending.

- About page: app version, GitHub project link and stable-release update checks.

## Verification / 验证

The latest build, language matrix, APK metadata and remaining gates are recorded in [release preparation / 发布准备](../RELEASING.zh-CN.md) and [English release preparation](../RELEASING.en.md).
