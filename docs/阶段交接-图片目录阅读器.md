## 本阶段已经完成

### 页面来源与文件访问

- 新增 `PageSource` 抽象和 `PageSourceFactory`。
- 图片目录按自然序排列页面，例如 `1.jpg`、`2.jpg`、`10.jpg`。
- 页面 ID 由章节 ID 与文档 ID 稳定生成，页面流每次读取都会重新打开。
- `TreeAccess` 同时支持直接文件路径和 SAF 文档 URI。
- 压缩包与 PDF 当前返回明确的“不支持”结果，不会误当图片目录打开。

### 阅读进度

- 接通已有的 `reading_progress` 表，补齐 DAO、Repository、实体映射和依赖注入。
- 进入阅读器时恢复章节与页码；滑页后持久化当前页。
- 首次打开章节时回填章节总页数。
- 数据库仪器测试覆盖漫画父记录更新后阅读进度仍然保留。

### 阅读器界面

- 新增黑底横向分页阅读器，默认从右向左翻页。
- 支持点按显示/隐藏顶部和底部控制栏、页码滑杆、上一章和下一章。
- 详情页新增“开始阅读/继续阅读”，章节行可以直接进入对应章节。
- 返回详情页时重新加载数据，以显示阅读器刚回填的页数。
- 直接文件来源的封面使用 `file://`，不再错误构造 DocumentsProvider URI。

## 已知边界

- 当前仅支持“章节目录内直接放置图片”的内容；ZIP/CBZ/RAR/7z 与 PDF 尚未实现页面源。
- 尚无阅读方向、缩放模式、常亮等阅读设置。
- 尚未定义读完最后一页后的自动跳章与“已读”状态策略。
- 大图目前使用采样解码，但仍应使用超大图片和长章节补一次内存/流畅度验证。
