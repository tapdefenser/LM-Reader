# LM-Reader

面向 Android 的本地漫画阅读与翻译应用。第一步（界面框架 + 图库路径配置 + 扫描 + 图库 + 书架）已实现并在真机验证。

规划支持图片目录、CBZ、ZIP、PDF，单章节与多章节图库、书架分类、增量索引、漫画翻译和译文遮罩阅读。

## 当前进度

第一步已完成并通过真机验证：

- 首次启动直接进入设置里的图库路径配置页（一张路径表：图片与 CBZ/ZIP/PDF 由同一次扫描识别）；
- 选目录后立即加入并扫描；子目录与单/多章节改动即时生效；路径行可改名、可拖动排序；支持强制重新扫描与取消；
- 结构扫描（单章节 / 多章节）、40 项分批加载的图库、书架与分类；
- 每次启动做一次真实授权检测，并在界面上如实显示结论。

真机（小米 14 Pro / Android 15）实测索引 `/sdcard/Tachiyomi/downloads` 得到 762 部漫画、28543 章。

尚未实现：漫画详情与阅读器（P2）、翻译与译文遮罩（P3）、导出与备份（P4）。菜单中这些入口显示明确的阶段说明，不摆放未接线的空壳控件。
