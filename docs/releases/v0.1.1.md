# v0.1.1 — SEG 范围与 OCR 修正 / SEG scope and OCR fixes

发布日期 / Release date: **2026-10-02**. Version code: **3**. Package: **com.lmreader**. Android **8.0+ / API 26+**; **arm64-v8a / x86_64**.

## 中文

- 每部漫画的“翻译选项 → SEG 提取范围”增加“气泡”“游离文字”“气泡+游离文字”，默认两者；按漫画保存，并固定到新任务的快照中。
- 猫爪 SEG 积木继续只接收图片，读取任务的提取范围，不增加步骤参数，已有工作流格式保持兼容。
- 调整 SEG 去重，保留相邻重叠气泡和有效的多个掩码连通区域。粘连气泡中的多个文字块建立独立识别目标，减少漏字与合并识别。
- 本地 OCR 和 API 气泡图片使用轮廓隔离裁图；游离文字裁图排除气泡像素，避免混入对话。
- 同一区域的 OCR 排版换行按语言连接：中日文接续，英文和韩文保留词间空格，减少机翻输入被换行打断。
- 数据库升级到 schema 12，保留漫画、已有译文和队列快照；旧漫画和旧任务默认提取气泡与游离文字。

使用与 v0.1.0 相同的 RSA-4096 发布证书，可覆盖安装。修改提取范围作用于新识别任务；已有译文可通过重新翻译更新。

## English

- Per-manga Translation options now offer bubbles, free text, or both under SEG text scope. Both is the default. The choice is saved per manga and captured in new task snapshots.
- The Cat-paw SEG step still accepts only an image and reads the task's scope; existing workflow formats remain compatible.
- SEG deduplication retains adjacent overlapping balloons and significant mask components. Separate text blocks in connected balloons become independent recognition targets to reduce omissions and combined OCR.
- Local OCR and API bubble attachments share contour-isolated crops. Free-text crops exclude balloon pixels to avoid capturing dialogue.
- OCR joins layout line breaks within each region using source-language spacing: Chinese/Japanese continue directly; English/Korean preserve word spaces.
- Database schema 12 preserves manga settings, saved translations and queue snapshots. Older manga settings and task snapshots default to both text kinds.

The APK uses the same RSA-4096 signing certificate as v0.1.0 for in-place upgrades. Scope changes apply to new recognition tasks; retranslate saved pages to update their results.
